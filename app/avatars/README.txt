Drop .png, .webp, .jpg or .gif images in this folder to add avatars.

- The file name becomes the avatar name: "rem_smile.png" shows as "rem smile".
- Any size works; images are center-cropped to a square and shrunk automatically.
- Only the HOST's folder matters: the host sends the avatars to every player.
- Restart the game (reload the host page) after adding files.
